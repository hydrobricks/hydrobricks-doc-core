Detailed Description

Records the model values over time: the subbasin (aggregated) values per subbasin, and the hydro unit (distributed) values per unit. The subbasins are indexed in processing order (upstream first, the outlet last); the hydro units are indexed globally, in the order of the subbasins.

◆ GetFractionIndexForComponent()

int Logger::GetFractionIndexForComponent ( const string & componentName) const
nodiscard

Find the land-cover fraction series that weights a logged hydro-unit component to a basin (area) average. A component is matched to its land cover by name: the land cover itself (<cover>:) or one of its surface components (<cover>_snowpack:, <cover>_canopy:). Returns the index into _hydroUnitFractions or -1 if the component is not tied to a land cover (then a fraction of one applies, i.e. it spans the whole unit).

Parameters
componentNamethe logged component label (e.g. "forest_canopy:water_content").
Returns
the fraction index, or -1 if none.
